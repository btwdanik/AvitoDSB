# Решение задачи Avito Data Science Bootcamp

**Кратко про решение:** данный ноутбук подбирает 50 объявлений для каждого поискового запроса. Сначала мы находим кандидатов через `E5`, `BM25` и символьный `TF-IDF`, затем сортируем их с помощью `LightGBM`. Модель использует 54 признака, включая историю запросов, географию и вероятности классификатора услуг.

### 1. Что делает ноутбук

1. **Подготавливает данные:** заполняет пропуски, нормализует текст, убирает
   стоп-слова и приводит слова к основам для поиска по словам.
2. **Строит представления:** готовая `E5` кодирует запросы, заголовки и описания
   в векторы, `BM25` и символьный `TF-IDF` оценивают текстовые совпадения.
   Веса `E5` не дообучаются, векторы сохраняются в кэш `.npy`.
3. **Собирает кандидатов:** объединяет лучшие объявления по смыслу, словам,
   географии и истории похожих запросов. Дополнительно обучает `ServiceNet`,
   которая по вектору запроса предсказывает вероятности микрокатегорий услуг.
4. **Обучает ранжировщик:** рассчитывает 54 признака для пары "запрос - объявление"
   и обучает `LightGBM`. Число деревьев выбирает на валидации,
   затем оценивает качество на отдельном тесте.
5. **Формирует ответ:** переобучает ранжировщик на всех подготовленных группах
   и выбирает по 50 объявлений из каталога бенчмарка для каждого запроса.


### 2. Какие признаки используем

Полный список из 54 признаков задан в `FEATURES` внутри ноутбука.
Основные группы:

| Группа | Что учитываем |
|---|---|
| Смысл текста | Сходство запроса с заголовком и полным текстом по `E5`, отставание от лучшего совпадения в каталоге. |
| Совпадения текста | `BM25` по заголовку, полному тексту и фильтрам; символьный `TF-IDF`; нормализованные оценки; долю совпавших слов, вхождение запроса и совпадения чисел. |
| История запросов | Какие объявления и микрокатегории выбирали для похожих запросов, близость к ближайшему запросу из истории, встречался ли запрос раньше. |
| География | Совпадение локации, расстояние, наличие координат центра локации, предпочтения между локациями из истории и склонность похожих запросов к поиску в своей локации. |
| Объявление | Популярность, рейтинг, число отзывов, цена, микрокатегория, длина заголовка и описания, скрытый телефон и запрет сообщений. |
| Запрос и фильтры | Длина запроса и число слов, наличие фильтров, категория и её совпадение, соответствие виду и типу услуги, рейтинг не ниже 4 при наличии фильтра рейтинга. |
| Классификатор услуг | Вероятность микрокатегории объявления по `ServiceNet`, её отношение к максимальной вероятности и неопределённость прогноза. |
| Общие оценки | Комбинации текстовых оценок, смыслового сходства и географических поправок. |

### 3. Результат

Ответ сохраняется в `/kaggle/working/answer.csv`: колонки `query_id` и `answer`,
в каждой строке - 50 уникальных `item_id` через пробел.
Модели, кэш векторов и локальные метрики находятся в `/kaggle/working/artifacts/`.

**Качество:** используем `Recall@50` - долю подходящих объявлений, попавших
в первые 50, в среднем по запросам. После запуска оценка записывается в
`artifacts/metrics.json`. Сохранённые в ноутбуке логи относятся к прежнему запуску,
они не подтверждают качество текущей версии кода.
